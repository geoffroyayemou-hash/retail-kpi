# Retail Demand & Staffing Model

Python + Tableau: retail demand and staffing model.
ANOVA applied across day-part and day-of-week to eliminate labor cost overruns.

## Tools
Python - Pandas - NumPy - Matplotlib - Tableau

## How to Run
pip install pandas numpy matplotlib
python analysis.py

## Key Findings
- ANOVA p-value (day-of-week): < 0.001
- Peak demand: Friday & Saturday evening
- Labor cost overruns eliminated after model adoption
